# Doodles

Original hand-drawn-style illustrations made for this project (no third-party artwork):
ink outlines (`#1E1C1A`, stroke 2.5, round caps and joins, slightly uneven curves) with fills
only in lime `#B6F04A`, blue `#2F4BC9` or white.

rocket · lightbulb · compass · grad-cap · laptop · books · paper-plane · star · sparkle ·
squiggle (underline) · trophy · magnifier

`../logo.svg` combines the compass with "Career Recommender" set in Manrope ExtraBold
(SIL OFL, converted to outlines). These files may be reused with the rest of the project.
