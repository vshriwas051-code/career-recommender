# Avatar credits

The SVGs in this folder are **Open Peeps** by **Pablo Stanley** (https://www.openpeeps.com),
released under **CC0 1.0** (public domain): https://creativecommons.org/publicdomain/zero/1.0/

They were generated **once** with DiceBear's `open-peeps` style
(https://www.dicebear.com/styles/open-peeps), using generic seeds and only friendly expressions
(`face=smile,smileBig,smileTeethGap,cute,calm,cheeky,lovingGrin1`, `maskProbability=0`).
They are saved here so the app never calls the DiceBear API at runtime and works offline.
Each file also carries its licence in its embedded `<metadata>`.

The app picks one avatar per student from a hash of their SRN (`career.ui.avatar_for`).
